# Configuration-drone

Configuration Betaflight pour un drone FPV 5 pouces équipé d’un châssis
ImpulseRC Apex.

## Captures d’écran et enregistrements

Les captures d’écran et les enregistrements servent à documenter un réglage ou
un problème ; ils ne doivent pas être ajoutés au dépôt à la place de la
configuration texte. Joindre le fichier directement à l’issue GitHub, avec un
nom de fichier simple et une taille raisonnable.

Si le téléversement échoue, joindre un fichier texte nommé `analyse.log`
contenant au minimum :

```text
fichier: <nom du fichier>
date: <date et heure avec fuseau>
appareil: <appareil et application utilisés>
erreur: <message exact affiché>
```

Retirer du journal les numéros de série, identifiants radio, mots de passe et
autres données personnelles. Sans la capture ou le message d’erreur exact, il
est impossible de déduire de manière fiable le réglage Betaflight à appliquer.
